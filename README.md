# jw1 개인 WIKI 비서 안내

Google 연결 전에 읽을 앱 소개와 개인정보 안내의 정적 문서 소스입니다.

- 앱 소개: `docs/index.html`
- 개인정보 안내: `docs/privacy/index.html`
- 게시 소스: GitHub Pages의 `main` 브랜치 `/docs`
- 빌드·서버 코드·JavaScript·외부 글꼴·분석 도구·입력 폼 없음
- 상대 경로를 사용하므로 프로젝트 기본 주소와 독립 도메인에서 같은 파일을 사용할 수 있음

게시 주소:

- 앱 소개: https://k-im-jinwoo.github.io/jw1-app-docs/
- 개인정보 안내: https://k-im-jinwoo.github.io/jw1-app-docs/privacy/

두 문서는 기존 포트폴리오와 별도의 저장소에서 게시합니다. OAuth 설정과 기존 Drive·Calendar 연결은 이 저장소에서 변경하지 않습니다.

GitHub Pages 기본 주소를 사용하며 `CNAME` 파일이나 별도 도메인 연결은 사용하지 않습니다. 별도 검토 자료·운영 기록·자격증명은 이 저장소나 `docs/`에 포함하지 않습니다. Google 소유권 검증과 OAuth 등록 가능 여부는 공개 URL의 정상 동작과 별도로 확인해야 합니다.
